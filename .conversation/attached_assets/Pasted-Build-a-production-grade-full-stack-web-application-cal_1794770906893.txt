Build a production-grade, full-stack web application called **"Veloce Engine"** — an automated, one-click Viral Content & Narrative Synthesis Studio designed to turn long-form streams, VODs, and raw gameplay into algorithm-compliant, monetizable short-form videos ready for multi-platform deployment.

### 1. DESIGN SYSTEM & EXECUTIVE UI/UX
- **Aesthetic:** High-ticket, institutional dark-mode SaaS aesthetic inspired by Linear, Vercel, and Frame.io. Deep obsidian background (`#09090B`), elevated matte charcoal cards (`#121215`) with subtle `1px solid rgba(255,255,255,0.08)` borders, crisp typography (`Inter` + `JetBrains Mono` for telemetry/timestamps), and electric emerald (`#10B981`) / amber (`#F59E0B`) status accents.
- **Zero-Friction "One-Click" Workflow:** Any operator must be able to paste a YouTube/Twitch/Kick URL (or select from live trending sources), pick a Monetization & Transformation Preset, and click **"Generate & Package Batch"** — watching real-time pipeline stages progress visually from ingestion to ready-to-publish assets.

### 2. CORE ARCHITECTURE & TECH STACK
- **Frontend:** React, TypeScript, Tailwind CSS, Lucide Icons, Framer Motion (smooth pipeline progress transitions), and an interactive vertical video preview player with timeline scrubbers and toggleable overlay layers.
- **Backend & Database:** Node.js/Express API with PostgreSQL + Drizzle ORM (`projects`, `source_videos`, `generated_clips`, `monetization_campaigns`, `platform_accounts`, `analytics_logs`).
- **Media & AI Worker Pipeline (Python + FFmpeg + LLM):**
  - Install and configure `yt-dlp`, `ffmpeg`, `faster-whisper`, and `opencv-python-headless` in the Replit environment.
  - Use OpenAI / Gemini API (via environment secrets) for viral hook detection, originality scoring, and commentary script generation, plus OpenAI TTS / ElevenLabs integration for voiceover synthesis.

### 3. KEY FEATURES & MODULES TO BUILD

#### A. Command Center ("One-Click Studio")
- **Input Bar:** Single-input URL bar supporting YouTube VODs, Twitch streams, or direct MP4 uploads, paired with a **"Trending Radar"** drawer showing top live gaming/cultural streams.
- **Algorithm-Safe Transformation Modes (Crucial for 2026 Platform Compliance):**
  1. *Commentary & Breakdown Mode (Recommended):* Generates an original AI voiceover intro + analytical mid-clip commentary, ducks source audio automatically, and adds dynamic picture-in-picture framing so videos pass YouTube/TikTok "Original Content" checks.
  2. *Multi-Clip Story Stitch Mode:* Merges the top 3–4 micro-moments into a cohesive listicle/narrative Short with animated chapter headers.
  3. *Bounty & Promo Overlay Mode:* Injects a selected sponsor audio bed at 15% volume, applies subtle Ken Burns zoom/color grading, and appends a custom end-card CTA.
- **Live Pipeline Visualizer:** Real-time step tracker showing: `[1. Audio & Chat Peak Extraction] -> [2. Viral & Context Scoring] -> [3. Original Commentary & Script Synthesis] -> [4. 9:16 Smart Facecam + Gameplay Render] -> [5. Compliance & Monetization Audit]`.

#### B. Built-In "Originality & Monetization Intelligence" Engine
- Every generated clip receives an **Originality & Reach Score (0–100)** before export based on:
  - Ratio of new commentary/voiceover vs. raw source audio.
  - Visual transformation delta (multi-layer framing, dynamic zoom, custom B-roll/text hooks vs. bare captions).
  - Hook strength in the first 2.5 seconds.
- **Monetization Hub:** A dedicated tab to manage active **CPM Bounty Campaigns** (attach sponsored music tracks or brand watermarks with auto-calculated payout tracking), **Affiliate Link Bio-Routers**, and **Platform Readiness Checklists** (tracking progress toward YouTube Partner thresholds and TikTok Creator Rewards).

#### C. Multi-Platform Deployment & SOP Training Drawer
- **One-Click Publish & Export Pack:** Export individual or bulk ZIP packages containing the rendered 1080x1920 60fps MP4, platform-specific SEO titles, high-CTR hooks, pinned comment CTAs, and hashtags—plus OAuth connector stubs/APIs for direct scheduling to YouTube Shorts, TikTok, Instagram Reels, and X.
- **Built-In Operator Playbook ("SOP Academy" Drawer):** An interactive slide-over guide built directly into the UI so anyone hired to operate the platform has step-by-step instructions on picking high-velocity sources, avoiding reused-content penalties, attaching CPM bounties, and scaling multi-account posting schedules.

### 4. EXECUTION INSTRUCTIONS

2. Build the complete backend media processing pipeline (`server/pipeline/`) using `yt-dlp`, `ffmpeg`, and LLM scoring with clean error handling and progress status polling.
3. Build the responsive, high-contrast React UI with seamless navigation between **Studio**, **Clip Vault & Editor**, **Monetization & Bounties**, **Distribution Scheduler**, and **Operator Playbook**.
